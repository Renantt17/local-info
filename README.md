# local-info

Desenvolvimento de um serviço web de previsão do tempo baseado na localização atual do usuário, utilizando HTML, CSS e JavaScript.

## Clima & Sol

O Clima & Sol permite consultar as condições meteorológicas da região do usuário, apresentando informações sobre temperatura, sensação térmica, umidade, velocidade do vento, previsão para os próximos dias e horários do nascer e pôr do sol.

**Acesse:** https://renantt17.github.io/local-info/

## Funcionalidades

- Identificação da localização atual do usuário.
- Consulta das condições meteorológicas.
- Previsão do tempo para os próximos 5 dias.
- Exibição dos horários do nascer e pôr do sol.
- Ícones representativos das condições climáticas.
- Tema visual dinâmico conforme o período do dia.
- Armazenamento da última consulta com LocalStorage.
- Interface responsiva.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Geolocation API
- LocalStorage
- Fetch API

## APIs utilizadas

- Open-Meteo: consulta de dados meteorológicos e previsão do tempo.
- BigDataCloud: identificação da localização a partir das coordenadas geográficas.

## Execução

1. Clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo `index.html` com a extensão Live Server.
4. Permita o acesso à localização pelo navegador.
